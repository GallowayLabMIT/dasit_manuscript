# dasit_manuscript
All figures for DASIT manuscript. Data used to generate figures can be downloaded from Zenodo: 10.5281/zenodo.22877088. RNA-sequencing data is deposited at GEO: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE349888 

Folders containing data to generate figures are similarly named in the Zenodo deposit. Users will have to change the datadir and path to load in data to match where the downloaded data is on their computer.
